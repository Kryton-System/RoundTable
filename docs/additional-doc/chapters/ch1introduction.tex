The Round Table Exchange (RTE) is a skill exchange system that automatically finds trade loops among three or more people without using money. Existing skill exchange platforms rely on direct 1-to-1 trades (where Person A trades directly with Person B) or time credits. The Round Table Exchange (RTE) solves this problem by representing users and skill offers as a graph, running a fast cycle-detection algorithm to find groups of 3 or more people who can satisfy each other's skill requests, and ranking trades by location and availability. The project includes a simple web app for skill listings, a multi-user trade confirmation workflow, and a synthetic data generator for testing. Trust scores, dispute resolution, and calendar sync are saved for future work.
