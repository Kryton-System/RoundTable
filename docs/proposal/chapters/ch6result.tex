\section{Project Budget (Bangladeshi Market Context)}

The budget for The Round Table Exchange (RTE) is planned for the Bangladeshi market, allocating a total estimated cost of \textbf{BDT 50,000} (Fifty Thousand BDT) across hosting, server tools, and testing setup.

Hosting the web application and matching server for 6 months requires cloud server infrastructure as shown in Table~\ref{tab:infrastructure-budget}.

\vspace{6pt}
\centering
\begin{tabularx}{\textwidth}{|X|l|r|}
\hline
\textbf{Resource / Service} & \textbf{Provider} & \textbf{Total Cost (BDT)} \\
\hline
