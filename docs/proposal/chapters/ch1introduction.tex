\section{Primary Objective}

The main goal of this project is to \textbf{build a graph-based multi-party matching engine for skill bartering}. When users post skills they can teach and skills they want to learn, the system represents these requests as a graph and automatically finds exchange loops among 3 or more people.

\section{Secondary Objectives}

\begin{enumerate}
    \item \textbf{Simple Web Application:} Build a simple web app where users can create profiles, offer skills, and request skills with location and time availability.
    \item \textbf{Trade Confirmation System:} Build an accept/reject workflow where all matched users in a trade loop can accept or reject a trade proposal.
    \item \textbf{Synthetic Test Data Generator:} Build a fake data generator to test how well the matching engine works as the number of users grows.
\end{enumerate}

\section{Explicit Non-Objectives}

To keep the project doable within one semester, the following features are not part of this project:
\begin{itemize}
    \item User trust and reputation rating algorithms.
    \item Legal or trade dispute resolution tools.
    \item SMS/Push notifications and calendar scheduling.
    \item Advanced graph databases like Neo4j.
\end{itemize}
