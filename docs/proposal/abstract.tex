This project presents \textbf{The Round Table Exchange (RTE)}, a skill bartering system that helps people exchange skills without money. Most skill-exchange websites only support direct 1-to-1 trades (where Person A trades directly with Person B) or use time credits. This system finds multi-party trade loops of 3 or more people (for example, Person A teaches Person B, Person B helps Person C, and Person C teaches Person A). The core part of this project is a graph matching engine that automatically discovers these trade loops and ranks them by user location and availability. It also includes a synthetic data generator to test the matching engine without needing live users, a simple web app for skill listings, and a multi-user trade confirmation workflow.
